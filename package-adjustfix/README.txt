Experimental XMEye Control DLL for VLC 3.0.24 x64.
Synchronizes XMEye filter checkboxes, keeps VLC adjust last when adding XMEye filters, skips redundant filter-chain changes.
Only installs libxmeyecontrol_plugin.dll. No change to zoom, filters or AVI demux.
NOT VALIDATED against the live gamma/brightness freeze yet.
Close VLC before running INSTALL-CONTROL.cmd or RESTORE-CONTROL.cmd.
A backup is stored under LOCALAPPDATA/VLC-XMEye-Control-Fix/backups.
If using Static Gate + Deblock + Zoom and image stalls, temporarily uncheck native VLC Adjust Image.
